# PSR SEO publishing checklist

Use this before promoting a project, community, developer, advisor or insight page into search.

## Entity and intent

- [ ] The page has one defined search intent and does not duplicate another PSR URL.
- [ ] The canonical URL is self-referencing and filter/query variants are noindexed.
- [ ] Names, address, contact details, ORN and any BRN/permit data match authoritative records.
- [ ] The page is reachable through ordinary HTML links.

## Content and evidence

- [ ] The introduction answers the visitor's decision directly.
- [ ] PSR analysis is original and clearly separated from sourced facts.
- [ ] Prices, payment plans, handovers and market figures have a real checked/published date.
- [ ] Primary sources are linked near the relevant evidence.
- [ ] Benefits, trade-offs, risks and suitability are stated without invented returns.
- [ ] A named author or expert reviewer is accountable for priority content.
- [ ] Material changes update `lastmod`; cosmetic changes do not.

## Media and accessibility

- [ ] PSR has the right to publish every image, video, plan and document.
- [ ] The hero and important images use crawlable HTML, dimensions and meaningful alt text.
- [ ] Responsive WebP/AVIF variants are available for large media.
- [ ] Floor plans and brochures do not contain confidential or obsolete terms.
- [ ] The page is usable at phone width and passes an overflow check.

## Structured data

- [ ] Schema exactly matches visible page content.
- [ ] Breadcrumb structured data matches the real hierarchy.
- [ ] Project pages use place/development types, not fabricated product offers.
- [ ] `Product` and `Offer` appear only for a real, visible, current unit.
- [ ] Advisor pages include complete, accurate `ProfilePage`/`Person` data.
- [ ] Articles include real publication/modification dates and responsible authorship.

## Conversion and compliance

- [ ] The enquiry route identifies the project, community, advisor or service.
- [ ] First/last landing, referrer and UTM fields reach the lead record.
- [ ] Telephone, WhatsApp, brochure, availability and appraisal actions are measurable.
- [ ] Dubai advertisements display the required permit/Madmoun verification where applicable.
- [ ] Availability and investment commentary carry appropriate qualification.

## Index decision

- [ ] The page is substantially useful without relying on runtime third-party enrichment.
- [ ] It meets the relevant Tier A/B threshold and has passed human editorial review.
- [ ] Only then is it added to the sitemap and allowed to index.
